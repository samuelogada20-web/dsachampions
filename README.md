# Data Structures & Algorithms (DSA) Champions 🏆

Welcome to my repository dedicated to mastering fundamental programming logic and problem-solving through Python! This project contains a structured collection of daily coding exercises.

## 🚀 Repository Structure
This repository features beginner to intermediate Python scripts aimed at strengthening core algorithmic thinking:
- `exe1.py` to `exe10.py` - Core foundational logic, loop implementations, and mathematical problem-solving exercises.
- `codan/` & `coden/` - Organized subdirectories for specific code categorization.

## 🛠️ Built With
- **Language:** Python 3.x
- **Environment:** Visual Studio Code / Terminal Execution

## 🏃 How to Run the Code Locally
To run any of the exercise scripts on your local computer, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project folder:**
   ```bash
   cd dsachampions
   ```
3. **Execute a script (for example, exercise 1):**
   ```bash
   python exe1.py
   ```
